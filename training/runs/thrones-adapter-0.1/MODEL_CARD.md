# Thrones Adapter 0.1 for Qwen3.5 4B

The first model weights trained by the Thrones project. It is a **LoRA adapter** (21.2 M parameters, 42 MB as GGUF f16) applied on top of the **unmodified** Qwen3.5 4B. It is not a new model and was not trained from scratch: the base model's knowledge and reasoning come from Alibaba Cloud's Qwen team.

| | |
|---|---|
| Base model | [Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B), Apache-2.0. Weight hashes in `config.json`. |
| Deployed as | `models/Qwen_Qwen3.5-4B-Q4_K_M.gguf` (bartowski Q4_K_M) + `models/thrones-adapter-0.1.gguf` via `llama-server --lora` |
| Adapter licence | MIT (Thrones project). The base model stays Apache-2.0. |
| Method | bf16 LoRA with Unsloth, r = 16, α = 16, dropout 0, targets q/k/v/o (8 full-attention layers) and gate/up/down (all 32 MLP blocks). Linear-attention layers not adapted. |
| Training | 1 epoch, 373 steps, batch 1 × grad-accum 8, cosine LR 1e-4, max 2,048 tokens, loss on assistant tokens only. 37 min on one RTX 5060 Ti 16 GB, peak 9.2 GB VRAM. Train loss 1.01 (first 50 steps) → 0.69 (last 120). |
| Data | 2,980 rows: 1,100 tool-use examples generated by our code with the real Thrones calculator (MIT); 700 human-annotated English↔Hinglish pairs from `findnitai/english-to-hinglish`, `source = 1` rows only (Apache-2.0); 600 Hindi prompt/answer pairs from `CohereLabs/aya_dataset` (Apache-2.0, human-written); 550 English first-turn conversations from `OpenAssistant/oasst2` (Apache-2.0, human-written); 30 identity rows written by the team. Manifest and hashes: `training/datasets/thrones_sft_v0.1.manifest.json`. **No outputs from Claude, Fable or any proprietary model.** |

## What these results do and do not show

- **Tool use is an in-distribution test.** The held-out problems come from the same code templates as the training examples (different numbers, de-duplicated prompts). The adapter learned to always use the calculator *for these kinds of problems* and to state the final figures clearly. Whether this transfers to differently-phrased questions has not been measured.
- **Much of the chrF gain is format.** The base model often wrapped translations in a preamble ("Maine is baat ko … translate kiya hai:"); the adapter returns just the translation. In one sample the adapter's meaning drifted from the source. Human review of translation quality has not been done.
- **No general intelligence gain is claimed or measured.** The regression sets show no loss and no gain. The adapter does not make the 4B as capable as the 9B (21/26 vs 24/26 on the hard set).
- **Identity answers are memorised** from 30 training rows (near-verbatim).
- One run, one seed; no variance estimate.

## Intended use

Selectable in Thrones as **"Thrones Adapter 0.1 (Qwen3.5 4B)"** (Balanced tier, marked Experimental). The default engine remains the unmodified Qwen3.5 9B, which is stronger on reasoning. Do not apply this adapter to any other base model (including Qwen3.5 9B): it only matches the 4B's shapes.

## Limits and risks

Inherits all limitations of Qwen3.5 4B (factual errors, outdated knowledge, possible biases). Fine-tuning on a small dataset can shift behaviour in ways the regression sets don't cover. Safety behaviour was not separately evaluated for this version.
